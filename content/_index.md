# Aprenda Git do zero, um passo de cada vez

Git é a ferramenta que guarda o histórico do seu projeto e permite que várias pessoas trabalhem no mesmo código sem pisar umas nas outras. Este guia ensina Git **na ordem em que você vai precisar dele**: primeiro sozinho no seu computador, depois com um repositório na internet e, por fim, colaborando com outras pessoas.

**Como usar este guia**

- Siga os capítulos em ordem. Cada um parte do ponto em que o anterior parou.
- Abra um terminal e **digite os comandos** da seção *Mão na massa*. Ler sem praticar não fixa.
- Ao final de cada capítulo, responda o *Teste-se* antes de seguir.
- Usaremos um projeto de exemplo chamado `receitas`, que cresce ao longo do guia.

**Você não precisa** saber programar. Só precisa de um computador, um terminal e um editor de texto.
